# Портфоліо — як редагувати й публікувати

Сайт статичний: без збірки, без бази даних. Відкриваєш `index.html` і бачиш сайт.

```
portfolio/
├── content.js        ← ВЕСЬ текст і всі креативи. Редагуєш тільки його
├── media/            ← відео, картинки, обкладинки
│   ├── betterme/
│   ├── aura/
│   └── automations/
├── raw/              ← сюди кидаєш оригінали відео перед стисканням (на сайт не потрапляє)
├── tools/compress-videos.sh
├── index.html        ← каркас (тут лише прев'ю для LinkedIn, og:…)
└── assets/           ← дизайн і логіка, зазвичай не чіпаєш
```

## Переглянути локально

Найпростіше: двічі клікни `index.html`.
Або в терміналі з папки `portfolio`: `python3 -m http.server 8000` → http://localhost:8000

## Додати креатив

1. Поклади відео в `media/betterme/` (або `media/aura/`).
2. У `content.js` знайди потрібний кейс і групу та додай рядок:

```js
{ src: "media/betterme/trauma-hook-01.mp4", title: "Inner child · UGC", format: "UGC",
  angle: "Childhood trauma as the hidden reason for anxiety", hook: "“Nobody told me this was trauma…”" },
```

Замість файлу можна вставити посилання на YouTube (Shorts теж), Vimeo або Google Drive: сайт сам розпізнає тип.
Порожній `src: ""` показує акуратну заглушку «coming soon».

Поле з `TODO` або порожнє на сайті не показується, тож чернетки не світяться.

## Щоб відео відкривалось у будь-кого

| спосіб | надійність | коментар |
|---|---|---|
| **mp4 у папці `media/`** | ✅ найкраще | грає всюди, без логінів і реклами. Стискай скриптом нижче |
| YouTube «Доступ за посиланням» | ✅ добре | не потрапить у пошук, але відкриється в усіх |
| Vimeo | ✅ добре | |
| Google Drive | ⚠️ ризиковано | потрібен доступ «Усі, хто має посилання», а при багатьох переглядах Drive блокує відтворення |

**Стискання** (один раз `brew install ffmpeg`):

```bash
# поклади оригінали в raw/, потім:
./tools/compress-videos.sh betterme     # → media/betterme/*.mp4 + обкладинки *.jpg
```

Ролик на 30 секунд стає приблизно 2–5 МБ. Після стискання raw/ можна чистити.

## Публікація (безкоштовно)

**Варіант A — Netlify Drop (найпростіший):**
зайди на https://app.netlify.com/drop і перетягни туди папку `portfolio`. Отримаєш посилання на кшталт `yuliia.netlify.app`.
Щоб оновити сайт: у Netlify → Deploys → перетягни папку ще раз.

**Варіант B — GitHub Pages (зручно редагувати з браузера):**
репозиторій → Settings → Pages → Deploy from branch `main`.
Після цього `content.js` можна правити прямо на github.com, і сайт оновлюється сам за хвилину.
Обмеження: 100 МБ на файл (через вебінтерфейс 25 МБ), тож відео обов'язково стискай.

Після публікації встав повну адресу обкладинки в `index.html` → `og:image` (картинка 1200×630, `media/og-cover.jpg`), щоб у LinkedIn і Telegram було гарне прев'ю.
